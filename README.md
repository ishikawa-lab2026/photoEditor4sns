# photoEditor4sns

> **Instagram / X（旧Twitter）への投稿に特化した、超軽量デスクトップ写真編集ツール**

手元の写真（JPEG等）を、Webサービスや重厚なフォトレタッチソフトを立ち上げる手間なく、ローカル単体で直感的に素早くサイズ調整・トリミング・基本補正して別名保存するためのデスクトップGUIアプリケーションです。

---

## 主な特徴

- 🔒 **プライバシー保護 & 忠実な色再現（Exif削除 & ICCプロファイル維持）**
  - スマホや一眼カメラで付与されたGPS位置情報・撮影日時・カメラ機種などのExif個人情報を完全に除去します。
  - 同時に、Display P3 や sRGB などの色空間情報（ICCプロファイル）は安全に引き継ぐため、SNS投稿時にも写真本来の鮮やかな発色を損ないません。
- 📐 **SNS特化のクロップ & 推奨解像度自動連動**
  - アスペクト比やズーム枠を選択するだけで、中央枠を配置し、**出力サイズが各SNSの推奨解像度へ自動的にセット**されます。
  - **全体最大枠（写真全体の構図重視）**:
    - **Instagram**: `1:1 (正方形 ➡ 1080×1080 px)`, `4:5 (縦長投稿 ➡ 1080×1350 px)`, `9:16 (ストーリーズ ➡ 1080×1920 px)`
    - **X (Twitter)**: `16:9 (標準横長 ➡ 1200×675 px)`, `4:3 (標準 ➡ 1200×900 px)`, `3:2 (写真標準 ➡ 1200×800 px)`, `3:1 (ヘッダー ➡ 1500×500 px)`
  - **【3倍ズーム枠】一部切り抜き（被写体クローズアップ用）**:
    - **Instagram**: `1:1 (3倍枠 3240×3240 ➡ 1080×1080 px)`, `4:5 (3倍枠 3240×4050 ➡ 1080×1350 px)`
    - **X (Twitter)**: `16:9 (3倍枠 3600×2025 ➡ 1200×675 px)`, `4:3 (3倍枠 3600×2700 ➡ 1200×900 px)`, `3:2 (3倍枠 3600×2400 ➡ 1200×800 px)`, `3:1 (3倍枠 3600×1200 ➡ 1500×500 px)`
  - **フリー / 元画像全体** (長辺 1920px Full HD)
- 🎯 **直感的な構図合わせ & 仕上がりサイズの可視化**
  - マウスドラッグ移動に加え、枠外クリックによる中心ジャンプ移動に対応。
  - **矢印キー（↑・↓・←・→）** による元画像 1px 単位（Shift 併用で 10px 単位）の精密な位置微調整が可能。
  - **3分割構図線（三分割法グリッド）** と **構図解像度 ➡ 最終保存解像度バッジ (例: 構図: 3240×3240 px ➡ 保存: 1080×1080 px)** をテキスト実寸で美しくリアルタイム表示。
  - 元画像が3倍枠より小さい場合でも比率を保って自動調整する安全クランプ機能。
  - プレビュー座標変換による丸め誤差（1〜2pxのズレ）を完全防止するアスペクト比厳密補正。
- 🎨 **精密かつ軽量な画像補正**
  - 明るさ・コントラスト・彩度を **`-1.00` 〜 `1.00`（初期値 `0.00`・中央揃え）** で直感的に補正。
  - スライダー操作に加えて **数値直接入力（0.01 刻み Spinbox）** にも双方向対応。
  - プレビュー適用状態が保持され、未適用の補正値がある場合は保存時に確認ダイアログでアシスト。
  - 透過PNG等のアルファチャンネルは白背景へ自動合成。
- ⚡ **超軽量・高い応答性**
  - プレビュー用縮小キャッシュ生成とリサイズデバウンス処理により、大画素写真でも軽快に動作。
  - 読み込み後のファイルハンドルは即時解放され、元ファイルのロックトラブルを防ぎます。
- 💾 **安全な出力・リサイズ設定**
  - 元画像と同じフォルダに `元ファイル名_sns.jpg` として保存（元画像の誤上書きを防止）。
  - SNS向け長辺上限リサイズ（1080px, 1350px, 1200px, 1500px, 1920px, 2048px, 元解像度のまま）および保存品質（70〜100）の選択が可能。

## 動作要件

- **OS**: Windows 10/11, macOS, Linux (Windows 向けに最適な日本語UIフォントを自動適用)
- **Python**: 3.10 以上
- **依存ライブラリ**: `Pillow >= 10.0.0`
- **開発用ライブラリ**: `pytest >= 9.0.0`

## クイックスタート

### 方法 1: `start.bat` から起動（Windows 推奨）

プロジェクトフォルダにある **`start.bat`** をダブルクリックするだけで自動的に起動します。
(`uv` または Python 仮想環境を自動検出して起動します)

### 方法 2: `uv` を使用して起動（推奨）

[`uv`](https://github.com/astral-sh/uv) がインストールされている場合、依存関係の解決と起動を1コマンドで行えます。

```bash
uv run python main.py
```

### 方法 3: 標準の `venv` / `pip` を使用して起動

```bash
# 仮想環境の作成と有効化 (Windows PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

# パッケージのインストール
pip install pillow>=10.0.0

# 起動
python main.py
```

## 使い方（5ステップ）

1. **写真を開く**: 左上の「📁 画像を開く (JPEG)」から編集したい写真を選択します。
2. **枠を選ぶ**: 右サイドバーから目的のSNSアスペクト比または3倍ズーム枠を選択します（全体構図・被写体クローズアップを自由に選択可能。出力サイズが自動でSNS推奨値に連動し、枠上に「構図 ➡ 保存サイズ」がリアルタイム表示されます）。
3. **位置を合わせる**: プレビュー上の枠をドラッグ、枠外クリック、または矢印キー（微調整）で、三分割グリッドに合わせて被写体を配置します。
4. **色調を整える**: 必要に応じて明るさ・コントラスト・彩度をスライダーまたは数値入力で調整し、「✨ 適用」を押します。
5. **別名で保存**: 出力サイズを確認し、「💾 別名で保存」をクリックします（自動で `元ファイル名_sns.jpg` が提案され、Exifが完全削除・色空間を維持して保存されます）。
