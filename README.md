# photoEditor4sns

> **Instagram / X（旧Twitter）への投稿に特化した、超軽量デスクトップ写真編集ツール**

手元の写真（JPEG等）を、Webサービスや重厚なフォトレタッチソフトを立ち上げる手間なく、ローカル単体で直感的に素早くサイズ調整・トリミング・基本補正して別名保存するためのデスクトップGUIアプリケーションです。

---

## 主な特徴

- 🔒 **プライバシー保護（Exif完全自動削除）**
  - 保存時に、スマホや一眼カメラで付与されたGPS位置情報・撮影日時・カメラ機種情報を完全に除去します。SNSへ安心してアップロードできます。
- 📐 **SNS特化のクロッププリセット**
  - **比率指定（元画像から最大枠）**: Instagram (1:1, 4:5, 9:16), X (16:9, 4:3, 3:2, 3:1), フリー
  - **推奨解像度固定枠（等倍切り抜き）**:
    - Instagram: `1080 × 1080 px` (正方形), `1080 × 1350 px` (縦長), `1080 × 1920 px` (ストーリーズ)
    - X (Twitter): `1200 × 675 px` (標準ポスト), `1500 × 500 px` (ヘッダー)
- 🎯 **直感的な構図合わせ**
  - プレビュー画面上で切り抜き枠をマウスドラッグで自由に移動。
  - **3分割構図線（三分割法グリッド）** と **実ピクセルサイズバッジ** をリアルタイム表示。
- 🎨 **軽量な画像補正**
  - 明るさ・コントラスト・彩度のスライダー調整。ボタン適用型（`✨ 適用`）により動作が重くなりません。
- 💾 **安全な出力・リサイズ設定**
  - 元画像と同じフォルダに `元ファイル名_sns.jpg` として保存（元画像の誤上書きを防止）。
  - SNS向け長辺上限リサイズ（1080px, 1200px, 1920px, 2048px, 元解像度のまま）および保存品質の選択が可能。
- ⚡ **超軽量・依存最小**
  - GUIはPython標準の `tkinter` / `ttk`、画像処理は `Pillow` のみ。外部DBや巨大フレームワークは一切不要です。

## 動作要件

- **OS**: Windows 10/11, macOS, Linux
- **Python**: 3.10 以上
- **依存ライブラリ**: `Pillow >= 10.0.0`

## クイックスタート

### 方法 1: `start.bat` から起動（Windows 推奨）

プロジェクトフォルダにある **`start.bat`** をダブルクリックするだけで自動的に起動します。
(`uv` または Python 仮想環境を自動検出して起動します)

### 方法 2: `uv` を使用して起動（推奨）

[`uv`](https://github.com/astral-sh/uv) がインストールされている場合、依存関係の解決と起動を1コマンドで行えます。

```bash
uv run python main.py
```

### 方法 3: 標準の `venv` / `pip` を使用して起動

```bash
# 仮想環境の作成と有効化 (Windows)
python -m venv .venv
.venv\Scripts\Activate.ps1

# パッケージのインストール
pip install pillow>=10.0.0

# 起動
python main.py
```

## 使い方（5ステップ）

1. **写真を開く**: 左上の「📁 画像を開く (JPEG)」から編集したい写真を選択します。
2. **枠を選ぶ**: 右サイドバーから目的のSNSアスペクト比または推奨ピクセル枠を選択します。
3. **位置を合わせる**: プレビュー上の枠をドラッグして、三分割グリッドに合わせて被写体を配置します。
4. **色調を整える**: 必要に応じて明るさ・コントラスト・彩度を調整し、「✨ 適用」を押します。
5. **別名で保存**: 出力サイズを確認し、「💾 別名で保存」をクリックします（自動で `元ファイル名_sns.jpg` が提案されます）。
